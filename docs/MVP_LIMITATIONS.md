# Ограничения MVP

- Система является рекомендательной.
- Реальные ордера не создаются.
- API-ключи бирж не используются.
- Поддерживается только long-направление.
- Нет кредитного плеча.
- Нет портфельной оценки корреляций и общего риска.
- SQLite подходит для локального MVP, но не для высокой параллельной нагрузки.
- Signal rules ограничены текущими breakout и mean reversion условиями.
- ML-модель может быть слабой или устаревшей; endpoint model-info показывает её возраст.
- Автоматический retraining требует сети и исторического parquet.
- Promotion gate не гарантирует прибыльность на будущих данных.
- Web-интерфейс предназначен для демонстрации, а не production trading terminal.
